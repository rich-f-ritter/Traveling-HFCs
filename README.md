# Traveling-HFCs

Census of Texas multifamily properties held in *traveling* HFC / PFC / housing-authority
tax-exemption structures — the deals whose exemptions are unwinding (HFC Chapter 394 deals die
1/1/2027 under HB 21 §13(i)).

- **Start here:** [`PROJECT_PLAN.md`](PROJECT_PLAN.md) — scope, tiers, phases, repo layout.
- **Methodology:** [`kit/`](kit/) — the statewide starter kit (legal framework, identification
  playbook, source directory, request templates, the Sarah case study).
- **Data:** [`data/`](data/) — the Yardi Matrix seed (335 properties, 13 sponsors) plus derived
  classification; [`schema/`](schema/) — the per-property census data model.

Scope: all traveling public-corporation deals, classified and tiered by kill-date. Depth:
public-record census on all, deep dossiers on a prioritized slice. Sources: public-record only.
